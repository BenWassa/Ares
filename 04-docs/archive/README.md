# Ares historical archive

Files in this directory are preserved only for provenance, research history, or reconstruction of earlier Ares decisions. They are **not production sources and not current editorial authority**.

- `legacy-synopsis.md` is the earlier full synopsis artifact. It contains superseded framing and unresolved historical claims; do not copy claims from it into production without source tracing.
- `legacy-interactive-maps.json` is the prepared pre-Ares-2 map configuration. Maps were explicitly deferred from the Ares 2.0 release and this file is not consumed by the build.

Current production/editorial sources live only under `src/content/`. Current product, architecture and ethical authorities remain under `04-docs/docs/`.

Git history preserves the removed Python builder, generated HTML, legacy CSS/JavaScript, process SVG and duplicated content tree.
